# mahnet — Android-приложение покупателя

Приложение для покупателей сайта **mahnet.ru**. Внутри — тот же сайт, что и в браузере (`https://mahnet.ru/`):
каталог, корзина, оформление заказа, вход покупателя, чаты, оплата. Вход запоминается, пока покупатель сам не нажмёт «Выйти».
Фото (например, для отзыва или возврата) можно выбрать из галереи или снять на камеру.

Всё, что вы меняете на сайте (товары, цены, оформление, тексты), сразу видно в приложении — пересобирать приложение не нужно.
Пересборка нужна только если меняется сам адрес сайта (`START_URL` в `MainActivity.kt`) или значок.

## Как собрать APK на GitHub (без Android Studio)
1. На https://github.com создайте новый репозиторий (лучше приватный), например `mahnet-buyer`.
2. Распакуйте архив и загрузите **все файлы проекта** (*Add file → Upload files*), включая папку `.github`
   (если GitHub её не принимает при выборе файлов — перетащите папку мышкой целиком).
3. Вкладка **Actions** → сборка *Build Buyer APK* запустится сама (или нажмите **Run workflow**).
4. Через 3–6 минут откройте зелёную сборку и внизу в **Artifacts** скачайте `buyer-apk` (там `app-debug.apk`).
5. Скопируйте `app-debug.apk` на телефон и откройте. Разрешите установку из этого источника.

Если сборка красная — пришлите последние строки из шага *Build debug APK* (с `error:`), я поправлю.

## Версии и обновление поверх старого
- Версия `1.0.N`, где N — номер сборки на GitHub. Все сборки подписаны одним ключом `app/buyer-release.p12`,
  поэтому новая сборка **ставится поверх** установленной, данные и вход сохраняются.
- **Не удаляйте и не меняйте `app/buyer-release.p12`**; репозиторий лучше держать приватным.
- Приложение имеет свой идентификатор `ru.mahnet.buyer` и ставится рядом с приложением продавца и курьера.

## Оплата
Страницы оплаты Т-Банка открываются внутри приложения; переходы в приложения банков (СБП) — через телефон.
После оплаты покупатель возвращается на сайт (страница `payresult.html`). Проверьте оплату на тестовом заказе после установки.

## Что внутри
- `app/src/main/java/ru/mahnet/buyer/MainActivity.kt` — окно сайта, выбор фото, кнопка «Назад» (по истории страниц), `START_URL` — адрес.
- `.github/workflows/build.yml` — автоматическая сборка на GitHub.

## Уведомления (push)
Приходят о смене статуса заказа, ответах продавца, возвратах. Включаются так: проект Firebase → файл `app/google-services.json` в проект → ключ в админке сайта
(вкладка «Push-уведомления»). Подробно: **`ПУШ_УВЕДОМЛЕНИЯ.md`**. Без `google-services.json` приложение работает как обычный сайт.

## Сброс версии на 1.0.0
Версия приложения — `1.0.N`: первая сборка после сброса получает **1.0.0**, дальше 1.0.1, 1.0.2…
В файле `app/version-base.txt` записано слово `auto`: при первой же сборке на GitHub оно само заменится
нужным числом (шаг «Версия (счёт с 1.0.0)» в *Actions*; затем сборка сама сохранит его в репозитории).
Ничего вписывать вручную не нужно. Если шаг «Запомнить счётчик версии» покажет красный значок (в репозитории запрещена запись
из Actions) — откройте *Settings → Actions → General → Workflow permissions* и включите *Read and write permissions*
либо впишите в `app/version-base.txt` число (номер последней сборки до сброса).
Чтобы снова сбросить счёт на 1.0.0 — запишите в `app/version-base.txt` слово `auto` и запустите сборку.
Внутренний номер Android (`versionCode`) при этом не уменьшается, поэтому новая сборка ставится поверх старой.
Если вы создали **новый репозиторий** (номера сборок начинаются с 1), старое приложение на телефоне нужно сначала удалить.
Не забудьте во вкладке админки «APK файлы» загрузить новый APK и указать версию `1.0.0` (или удалить старую запись),
иначе приложение будет предлагать «обновиться» до старой версии.
